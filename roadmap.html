Backend Developer Roadmap

Phase-Based • No Time Limit • Practical Learning Track

Phase 1 — JavaScript Basics Foundation
Why it matters: Every backend framework (Express, NestJS) is just JavaScript underneath. Shaky fundamentals here show up as bugs later that look like "framework problems" but aren't.
What to Learn
  • Variables: let, const (and why var is avoided)
  • Data types: Number, String, Boolean, Object, Array, null, undefined, and typeof
  • Type coercion basics (== vs ===)
  • Input/output (console.log, readline for console input)
  • Operators: arithmetic, comparison, logical, ternary
  • Conditions: if, else if, else, switch
  • Loops: for, while, do...while, for...of, for...in
  • Functions: declarations, parameters, default parameters, return values
  • Arrow functions and how this differs from regular functions
Projects
  • Console calculator (add/subtract/multiply/divide, handle divide-by-zero)
  • To-do list in console (add, remove, mark complete, list all — using an array)
  • Guess-the-number game (with limited attempts and hints)
  • Simple grade calculator (input marks, output grade using switch)
Phase 2 — Intermediate JavaScript Core JS
Why it matters: map/filter/reduce and destructuring show up constantly in real backend code — shaping API responses, transforming DB query results, and handling request bodies.
What to Learn
  • Arrays: push, pop, shift, unshift, slice, splice, indexOf, includes
  • Objects: property access, dynamic keys, Object.keys/values/entries
  • Array methods: map(), filter(), reduce(), find(), some(), every(), forEach()
  • String methods: split, trim, includes, replace, slice
  • Destructuring (arrays and objects, including nested)
  • Spread operator (...) for copying/merging
  • Rest operator (collecting function arguments)
  • Template literals & Scope (global, function, block; closures)
  • Callbacks and Higher-order functions
Projects
  • Student management system (CRUD stored as an array of objects)
  • Expense tracker (categorize expenses, calculate totals using reduce)
  • A simple library catalog (filter by author/genre, sort by year)
  • Closure-based counter/bank account simulator (private state via closures)
Phase 3 — Async JavaScript & Browser APIs Critical
Why it matters: Nearly every bug a junior backend dev hits early on is either "I don't understand async flow" or "I don't understand what a status code means." This phase prevents both.
What to Learn
  • The event loop (call stack, callback queue, microtasks)
  • Callbacks, "callback hell," and Promises (.then, Promise.all)
  • async/await syntax and error handling with try/catch
  • fetch() and working with JSON (JSON.stringify, JSON.parse)
  • HTTP methods (GET, POST, PUT, PATCH, DELETE) & Status codes
  • REST API concepts, CORS, and ES Modules (import/export)
Projects
  • Fetch and display data from a public API rendered in plain HTML
  • Build a mini REST client: buttons triggering requests against JSONPlaceholder
  • A "retry with backoff" fetch wrapper for robust error recovery
Phase 4 — HTML & CSS (Just Enough) Tooling
Why it matters: Enough to build a simple form or test page to hit your own APIs, not to become a frontend developer.
What to Learn
  • HTML structure, semantic tags, forms, and input types
  • CSS basics: selectors, box model, colors, typography
  • Flexbox (centering things and simple layouts)
  • Responsive design basics via media queries
Projects
  • A static HTML signup/login form with basic CSS styling
  • A simple "API tester" page calling your Phase 3 backend scripts
Phase 5 — Git & GitHub Essential
Why it matters: Non-negotiable for team workflows, tracking your projects, and job applications.
What to Learn
  • git init, add, commit, push, pull
  • Branching, merging, and resolving basic merge conflicts
  • .gitignore configuration (node_modules, .env)
  • Remotes, forks, pull requests, and README documentation
Projects
  • Push every project so far to GitHub with clean READMEs
  • Practice a solo "team" workflow: branch, change, PR, and merge
Phase 6 — Node.js Fundamentals Backend Core
Why it matters: Bridges the gap between running JavaScript in the browser and running it on a server environment.
What to Learn
  • Node architecture vs browser JS (no DOM, has fs/path)
  • The Node event loop and non-blocking I/O
  • NPM ecosystem, package.json, and semantic versioning
  • Core modules: File system (fs, fs.promises), Path
  • CommonJS (require) vs ES Modules (import)
Projects
  • A CLI tool reading a CSV/JSON file to print structured summaries
  • A simple file-based note-taking CLI stored locally
Phase 7 — Express.js Framework
Why it matters: The industry standard entry-point framework for building flexible HTTP servers and REST APIs in Node.
What to Learn
  • Routes, route parameters, and query parameters
  • Middleware (built-in, custom, and third-party like cors, morgan)
  • Request and Response objects in-depth
  • REST API design conventions, versioning, and CRUD operations
  • Environment variables with dotenv and centralized error handling
Projects
  • User authentication API (signup/login, hashed passwords, protected profile route)
  • A "notes" or "bookmarks" REST API with full CRUD
  • A simple blog API with nested resources (posts + comments)
Phase 8 — Databases & ORMs Storage
Why it matters: Real applications require persistence, transactional integrity, and scalable relational querying.
What to Learn
  • SQL basics: SELECT, INSERT, UPDATE, DELETE, WHERE, LIMIT
  • PostgreSQL setup (local or hosted via Supabase/Neon)
  • Relationships: one-to-many, many-to-many, foreign keys, joins
  • Database transactions and performance indexing
  • Using an ORM like Prisma for schema management and migrations
Projects
  • Rebuild your Phase 7 auth API with real PostgreSQL storage
  • Rebuild the blog API with proper relational schema using Prisma
  • An e-commerce schema tracking products, categories, and orders
Phase 9 — Authentication & Security Security
Why it matters: Securing endpoints, managing tokens safely, and preventing vulnerabilities is non-negotiable for production systems.
What to Learn
  • JWT architecture: access tokens, refresh tokens, expiration
  • Cookies vs sessions, httpOnly flags, and secure headers
  • Password hashing using bcrypt
  • Rate limiting, input validation via Zod/Joi, and logging basics
  • Mitigating SQL injection, XSS, and CSRF vulnerabilities
Projects
  • Add JWT auth flow (access + refresh) to your database API
  • Implement Role-Based Access Control (RBAC: Admin vs User routes)
  • Harden an existing project with rate limiting, input validation, and logging
Phase 10 — Advanced Backend Production Ready
Why it matters: Real-world applications demand real-time events, optimized list endpoints, secure file management, and robust documentation.
What to Learn
  • WebSockets and Socket.io for real-time bi-directional communication
  • File upload management via multer (local vs cloud storage like S3)
  • Background tasks, queues, and scheduled jobs (node-cron)
  • API documentation generation using Swagger / OpenAPI
  • Advanced list endpoint querying: pagination, filtering, and sorting
Projects
  • Add real-time comment updates to your blog API using Socket.io
  • Implement profile picture uploads stored on cloud buckets
  • Add pagination, filtering, and sorting to e-commerce product endpoints
  • Document your full API using Swagger for a live, testable docs portal
Phase 11 — FastAPI (Python Track - Optional) Alternative Track
Why it matters: Expands your technical stack into Python ecosystems, widely valued for data-heavy and AI-adjacent services.
What to Learn
  • Routes, path/query parameters, and automatic request validation
  • Pydantic models, response typing, and serialization
  • SQLAlchemy integration with PostgreSQL
  • Dependency injection architecture (Depends) and custom exceptions
Projects
  • Rebuild your Node/Express auth API in FastAPI to compare patterns
  • Build a task management API with user ownership using FastAPI & Postgres
Phase 12 — TypeScript Type Safety
Why it matters: Large-scale production codebases rely heavily on strict typing to eliminate runtime crashes and improve maintainability.
What to Learn
  • Basic types, type inference, interfaces, and custom types
  • Typing functions, arrays, objects, and basic generics
  • Typing Express request/response payloads and custom middleware
  • Configuring tsconfig.json and build/transpilation workflows
Projects
  • Rewrite your Phase 9 auth and role-based project entirely in TypeScript
  • Implement strict DTO typing for your Phase 10 e-commerce API
Phase 13 — Docker & Deployment DevOps
Why it matters: Ensures your app runs consistently across any hardware environment from development laptops to cloud servers.
What to Learn
  • Docker fundamentals: images, containers, and writing optimized Dockerfiles
  • Docker Compose for spinning up multi-container apps (Node app + Postgres)
  • Production environment isolation and configuration
  • Cloud deployment platforms like Render, Railway, or VPS instances
Projects
  • Containerize your TypeScript/PostgreSQL/JWT project using Docker Compose and deploy live
  • Deploy your FastAPI project independently to showcase multi-stack flexibility
